# Acme Salary Manager

An employee and salary management application designed for HR teams managing a workforce of approximately 10,000 employees across multiple countries.

## Core features

- Employee dashboard and directory
- Employee search and filtering
- Employee profile management
- Salary history with effective dates
- Salary reporting by currency
- Employee CSV export

## Engineering priorities

- Maintainable architecture
- Data validation and integrity
- Efficient employee search and pagination
- Automated testing
- Protection of sensitive employee salary information
